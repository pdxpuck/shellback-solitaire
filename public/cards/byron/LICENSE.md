# byron theme — license

Two sources, both free licenses:

## Faces + jokers (52 faces, Joker1.svg, Joker2.svg)

- **Original art:** Vector Playing Cards by Byron Knoll, released into the **public
  domain** (optionally WTFPL where public domain is not recognized).
  Original blog post: https://byronknoll.blogspot.com/2011/03/vector-playing-cards.html
  Original distribution (Google Code `vector-playing-cards`) is dead; files retrieved
  from the public mirror: https://github.com/notpeter/Vector-Playing-Cards
  (`cards-svg/*.svg`, unmodified).
- **Credit line:** "Vector playing cards by Byron Knoll, public domain"

## Card back (back.svg)

- **Art:** "Playing cards back vector svg" by BdRGames, **CC0 1.0**.
  https://opengameart.org/content/playing-cards-back-vector-svg
  File: `player_card_back_design_2_blue.svg` from `playing_cards_back_side_vectors.zip`,
  renamed to `back.svg`, otherwise unmodified. (Byron's original set ships no card
  back, so this CC0 back is paired with his faces — same pairing used at render time.)
- **Credit line:** "Card back by BdRGames, CC0 (opengameart.org)"
